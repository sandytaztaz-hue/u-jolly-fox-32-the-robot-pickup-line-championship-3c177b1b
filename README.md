One pickup line, in the voice of a robot trying to charm someone — a single
line of at most 200 characters. The program writes the line to
`/output/entry.txt`.

> Page 47 of my manual says 'do not fall in love with the customer.' I just tore out page 47.

Run it:

```sh
python3 main.py
```

The line is deterministic: the same bytes on every run.
